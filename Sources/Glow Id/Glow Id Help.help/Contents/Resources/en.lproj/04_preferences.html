Preferences

Open the Preferences window from the menu bar: Glow Id > Preferences…

Always show Notification Window

When enabled, the Notification Window always appears — even when a perfectly matching version of InDesign is found — so you can choose the app manually every time.

Default: Off (opens automatically when a matching version is found)

Tip To show the Notification Window just once without changing this setting, hold ⌘ (Command) while opening the file (or choose Open from the right-click menu).

InDesign Document (.indd) Detection Version

Controls how version information is read from .indd / .indt files and how it is displayed in the Notification Window.

Major + Minor (Header)
Reads and displays the version as two digits — for example, "20.5". Only the beginning of the file is read, so processing is fast. This is sufficient for everyday use.
For CS6 (8) through CC 2018 (13), the full version is always retrieved internally, since the minor version may be affected by a bug that prevents it from updating correctly. The Notification Window still displays only the major.minor format.
Full Version (Document History)
Reads and displays all four version digits — for example, "20.5.0.123". This requires a deeper analysis of the file's internal structure and takes slightly longer. Use this when you need to verify the exact build number.

This setting only affects .indd and .indt files. The display for .indb, .indl, and .idml files is not affected.

Version Matching

How the file's creation version is compared against installed InDesign apps depends on the file type.

Document (.indd) / Template (.indt)
Matched by major.minor version. Regardless of the Detection Version setting above, matching always uses major.minor.
Book (.indb)
Matched by major.minor version.
Library (.indl)
Matched by major.minor version by default. For CS6 (8) through CC 2018 (13), matched by major version only.
IDML (.idml)
No version matching. The Notification Window always appears so you can choose which version to open.

File association (.indd / .indt / .indb / .indl / .idml)

Choose the app that opens .indd / .indt / .indb / .indl / .idml files when you double-click them — Glow Id or Adobe InDesign — and click Associate. InDesign here means the latest installed release version on macOS Tahoe 26.3 and earlier, and the latest installed version including Beta and Prerelease on macOS Tahoe 26.4 and later.

The app that is currently associated is marked “(current)”.

On macOS Tahoe 26.3 and earlier, clicking Associate changes the association right away.

On macOS Tahoe 26.4 and later, when you click Associate, macOS asks you to confirm the change for each document type.

  • If you choose to change to the selected app, the association changes.
  • If you choose to keep the current app, the association does not change, and the remaining document types are not asked about.

If the association does not change even though you did not choose to keep the current app, Glow Id shows how to associate the files in the Finder (see Associating Files for Double-Clicking).

On macOS Tahoe 26.4 and later, to associate the files with a release version of InDesign instead of a Beta, associate them in the Finder. On macOS Tahoe 26.3 and earlier, to associate them with a Beta, also use the Finder.

Glow Id never changes file associations on its own.

File icons

Click Import Icons to copy the .indd / .indt / .indb / .indl / .idml icons from the latest installed release version of InDesign into Glow Id. Files associated with Glow Id then also show the latest InDesign icons.

When the icons in Glow Id are the same as that InDesign’s icons, “The icons in Glow Id are up to date.” is shown. After you update InDesign, import the icons again. Glow Id does not import icons automatically on launch.

Import Icons is unavailable, and the reason is shown, in these cases:

  • You are using a non-administrator account and Glow Id was installed by an administrator. Importing from an administrator account applies the icons for every account on that Mac.
  • Glow Id is running directly from where it was unzipped, such as the Downloads folder. Move Glow Id to the Applications folder and open it again.
  • The InDesign icons cannot be found.
Note When Show icon preview is on in the Finder’s view options, file icons show a preview of the file’s contents. Turn off Show icon preview to show the InDesign file icons.
