使い方

ファイルを開く

方法1：ダブルクリック（推奨）

.indd / .indt / .indb / .indl / .idmlファイルをGlow Idに関連付けておくと（関連付けの方法）、ファイルをダブルクリックするだけでGlow Idが起動し、バージョンを判定して適切なInDesignで開きます。

  1. .indd / .indt / .indb / .indl / .idmlファイルをダブルクリックします。
  2. Glow Idが起動し、ファイルのバージョンを判定します。
  3. バージョンが一致するInDesignが見つかれば自動的に開きます。見つからない場合や、確認が必要な場合は通知ウインドウが表示されます。
ヒント ダブルクリックでGlow Idが起動しない場合は、ファイルがGlow Idに関連付けられていません。関連付けの方法を参照してください。

方法2：Dockアイコンにドロップ

  1. Dockに表示されているGlow Idのアイコンに、ファイルをドラッグ＆ドロップします。
  2. ファイルのバージョンが判定され、一致するInDesignが自動的に起動します。
  3. バージョンが一致するアプリが見つからない場合や、確認が必要な場合は通知ウインドウが表示されます。

方法3：メニューから開く

  1. メニューバーの「ファイル」→「開く…」（⌘O）をクリックします。
  2. ファイル選択ダイアログでファイルを選びます。複数ファイルを同時に選択できます。

ダブルクリックで開くための関連付け

Glow Idは、ファイルの関連付けを自動では変更しません。ダブルクリックでGlow Idを使うには、.indd / .indt / .indb / .indl / .idmlファイルをGlow Idに関連付けてください。

関連付けは、環境設定の「関連付ける」で行えます（ファイルの関連付け）。

環境設定で関連付けが変わらなかった場合は、Finderで次のように関連付けます。

  1. Finderで.inddファイルを選び、「ファイル」メニューの「情報を見る」を選びます。
  2. 「このアプリケーションで開く」でGlow Idを選びます。
  3. 「すべてを変更…」をクリックし、確認のメッセージで「続ける」をクリックします。
  4. .indt / .indb / .indl / .idmlファイルでも、同じ操作をします。

元に戻すには、環境設定で「Adobe InDesign」を選んで「関連付ける」をクリックするか、同じ手順でInDesignを選んでください。

IDMLファイルについて

IDMLは異なる下位バージョンで開くためのファイル形式なので、常に通知ウインドウが表示されます。警告も表示されません。開くバージョンのInDesignを選択してください。

複数ファイルをまとめて処理する

複数のファイルを一度に開くと、1ファイルずつ順番に処理します。通知ウインドウが表示される場合は、1つのウインドウを閉じてから次のウインドウが表示されます。処理が終わってからまとめてInDesignで開きます。

⌘ キーを押しながら開く

バージョンが一致するInDesignが見つかった場合、通常は自動的に開きます。⌘（Command）キーを押しながらファイルを開くと、バージョンが一致していても通知ウインドウを表示します。

Glow Idは自動で終了する

ファイルを開いた後、Glow Idは自動的に終了します。InDesignの作業中にGlow Idを手動で終了する必要はありません。

ヒント 通知ウインドウの「終了」ボタンを使うと、現在起動中のInDesignをGlow Idから終了させることができます。

InDesignのアイコンを取り込む

Glow Idに関連付けたファイルのアイコンは、Glow Idの中にあるアイコンで表示されます。InDesignの最新アイコンにするには、環境設定の「アイコンを取り込む」をクリックしてください（ファイルアイコン）。Glow Idが起動時に自動で取り込むことはありません。

InDesignをアップデートしたときは、取り込み直してください。
