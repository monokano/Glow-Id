環境設定

設定ウインドウは、メニューバー「Glow Id」→「設定…」から開きます。

常に通知ウインドウを表示する

オンにすると、バージョンが完全に一致するInDesignが見つかった場合でも、自動的に開かず必ず通知ウインドウを表示します。

デフォルト：オフ（一致するバージョンがあれば自動で開く）

ヒント 設定を変えずに一時的に通知ウインドウを表示したい場合は、⌘（Command）キーを押しながらファイルをドロップ（または右クリックメニュー「開く」を選択）してください。

InDesignドキュメント（.indd）の検出バージョン

.indd / .indtファイルのバージョン取得方法と通知ウインドウでの表示を切り替えます。

メジャー＋マイナー（ヘッダー）
バージョンを「20.5」のようにメジャー.マイナーの2桁で取得・表示します。ファイルの先頭部分のみを読み取るため、高速に処理できます。通常の作業ではこの設定で十分です。
CS6 (8) ～CC 2018 (13) は、マイナーバージョンが更新されないバグの影響が懸念されるので、常にフルバージョンを取得します。通知ウインドウにはメジャー.マイナーの2桁を表示します。
フルバージョン（ドキュメントヒストリー）
バージョンを「20.5.0.123」のように4桁すべてで取得・表示します。ファイルの内部構造を詳細に解析するため、メジャー＋マイナーより時間がかかります。細かい番号まで確認したい場合に使います。

この設定は.indd / .indtにのみ影響します。.indb / .indl / .idmlの検出方法は変わりません。

バージョン一致判定

ファイルの作成バージョンとInDesignアプリのバージョンを比較する方法は、ファイルの種類によって異なります。

ドキュメント (.indd) / テンプレート (.indt)
メジャー.マイナーで一致判定します。検出バージョンの設定に関わらず、比較はメジャー.マイナーで行います。
ブック (.indb)
メジャー.マイナーで一致判定します。
ライブラリ (.indl)
原則メジャー.マイナーで一致判定します。CS6 (8) ～CC 2018 (13) はメジャーのみで一致判定します。
IDML (.idml)
一致判定はしません。常に通知ウインドウが表示され、開くバージョンを選択します。

ファイルの関連付け（.indd／.indt／.indb／.indl／.idml）

.indd / .indt / .indb / .indl / .idmlファイルをダブルクリックしたときに開くアプリを、「Glow Id」と「Adobe InDesign」から選び、「関連付ける」をクリックします。InDesignは、macOS Tahoe 26.3まではインストールされている正式版の最新バージョン、macOS Tahoe 26.4以降はBeta・Prereleaseも含めた最新バージョンです。

現在関連付けられているアプリには「（現在）」と表示されます。

macOS Tahoe 26.3までは、「関連付ける」をクリックするとそのまま関連付けが変わります。

macOS Tahoe 26.4以降は、「関連付ける」をクリックすると、macOSが書類の種類ごとに確認のメッセージを表示します。

  • 「“InDesign (Beta)”に変更」のように、選んだアプリに変更するボタンをクリックすると、関連付けが変わります。
  • 「“Glow Id”のままにする」のように、今のアプリのままにするボタンをクリックすると、関連付けは変わりません。残りの種類の確認も表示しません。

どちらも選んでいないのに関連付けが変わらなかった場合は、Finderで関連付ける方法が表示されます（関連付けの方法）。

macOS Tahoe 26.4以降で、Betaではなく正式版のInDesignに関連付けたいときは、Finderで関連付けてください。macOS Tahoe 26.3まででBetaに関連付けたいときも、Finderで関連付けてください。

Glow Idが自動で関連付けを変更することはありません。

ファイルアイコン

「アイコンを取り込む」をクリックすると、インストールされている正式版の最新InDesignから、.indd / .indt / .indb / .indl / .idmlのアイコンをGlow Idに取り込みます。Glow Idに関連付けたファイルのアイコンをInDesignの最新アイコンにするためです。

Glow Idの中にあるアイコンがそのInDesignのアイコンと同じときは、「Glow Idの中にあるアイコンは最新です。」と表示されます。InDesignをアップデートしたときは、取り込み直してください。Glow Idが起動時に自動で取り込むことはありません。

次のときは「アイコンを取り込む」をクリックできず、理由が表示されます：

  • 管理者でないアカウントで、管理者がインストールしたGlow Idを使っているとき。管理者のアカウントで取り込むと、そのMacのすべてのアカウントに反映されます。
  • ダウンロードフォルダなど、展開した場所からそのまま起動しているとき。Glow Idを「アプリケーション」フォルダへ移動してから、起動し直してください。
  • InDesignのアイコンが見つからないとき。
メモ Finderの表示オプションで「アイコンプレビューを表示」がオンのときは、アイコンにファイルの中身のプレビューが表示されます。「アイコンプレビューを表示」をオフにすると、InDesign用のファイルアイコンになります。
